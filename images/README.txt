Папка для фоновых картинок ценников и воблеров.
===================================================

Содержит все фоны проекта: как базовые (Alaska, Корона, Снеки, А5 и др.),
так и тематические (рыба, закуски, напитки).

Файлы автоматически подхватываются приложением:
- При работе онлайн (http/https): через индекс bg_index.json.
- При работе локально (file://): через кнопку «Выбрать папку с фонами...»
  (достаточно указать эту папку images/ один раз).

Поддерживаемые форматы: .jpg, .jpeg, .png, .webp, .gif

Для обновления онлайн-индекса после добавления новых картинок запустите:
    python gen_bg_index.py
