Каталог для графических (объёмных / декоративных) шрифтов.
================================================================

Эти шрифты подключаются локально через @font-face (см. конец style.css)
и появляются в выпадающих списках «Шрифт заголовка» и «Шрифт цены»
в группе «Графические (объёмные)».

Текущие подключённые шрифты
---------------------------
Имена семейств (font-family) прочитаны напрямую из name-table файлов:

  Файл                        Семейство (font-family)    Стиль
  --------------------------- -------------------------- --------
  DuoDunkel.ttf               Duo Dunkel                 Regular
  DuoLicht.ttf                Duo Licht                  Regular
  Sortefaxno2turquoise.ttf    SortefaxNo2Turquoise       Medium

В @font-face (style.css) и в <option> (index.html) имена семейств
должны СОВПАДАТЬ с теми, что указаны в таблице выше, иначе браузер не
сопоставит файл с font-family и шрифт не применится.

Как заменить / добавить шрифт
-----------------------------
1. Положите .ttf/.woff2 в этот каталог.
2. Проверьте настоящее имя семейства (оно зашито внутри файла; имя файла
   может от него отличаться — как в случае SortefaxNo2Turquoise).
3. В style.css добавьте/исправьте блок @font-face:
     font-family: 'ИМЯ СЕМЕЙСТВА';   ← должно совпадать с TTF
     src: url('fonts/имя-файла.ttf') format('truetype');
4. В index.html в обоих <select> (id="titleFont" и id="priceFont")
   в группе «Графические (объёмные)» добавьте/исправьте:
     value="'ИМЯ СЕМЕЙСТВА', sans-serif"   и подпись <option>.

ВАЖНО — лицензия
----------------
Эти шрифты распространяются на условиях «Personal Use» / бесплатны только
для личных некоммерческих целей. Для печати воблеров на продажу / в рознице
необходимо приобрести коммерческую лицензию у автора каждого шрифта либо
заменить на свободный аналог (лицензия OFL/SIL).

КИРИЛЛИЦА
---------
Проверяйте поддержку кириллицы у каждого шрифта. Если шрифт содержит только
латиницу, русские буквы отобразятся системным фолбэком (sans-serif).
Формат .woff2 весит меньше .ttf — предпочтительнее использовать его,
а .ttf оставлять как резервный src.
