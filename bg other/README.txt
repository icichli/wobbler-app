Папка для дополнительных фоновых картинок воблеров.
===================================================

Файлы из этой папки попадают в выпадающий список «Выбрать фоновую
картинку» → подменю «Дополнительно (из «bg other»)».

Поддерживаемые форматы: .jpg .jpeg .png .webp .gif


ДВА РЕЖИМА ПОДКЛЮЧЕНИЯ
=====================

Режим зависит от того, как открыт проект:

1. ОНЛАЙН (проект на веб-сервере по http:// или https://)
   -------------------------------------------------------
   Фоны подгружаются АВТОМАТИЧЕСКИ при открытии страницы — без всяких
   кликов. Для этого рядом с index.html должен лежать файл bg_index.json
   со списком картинок.

   Что делать при изменении папки «bg other» (добавили/удалили файл):
     1) локально запустите:  python gen_bg_index.py
        (он перечитает папку и обновит bg_index.json);
     2) залейте обновлённый bg_index.json на сервер рядом с index.html.

2. ЛОКАЛЬНО (index.html открыт двойным кликом, протокол file://)
   -------------------------------------------------------------
   На file:// браузер блокирует чтение файлов, поэтому автоматической
   загрузки нет. Фоны кэшируются ОДИН ручным выбором папки:

     1) в конструкторе, раздел «Фоны и заливка», нажмите
        «📂 Выбрать папку с фонами...» и укажите эту папку («bg other»);
     2) картинки прочтутся и сохранятся в браузере (IndexedDB),
        появятся в подменю «Дополнительно».

   При следующих открытиях страницы фоны подгружаются автоматически —
   папку выбирать снова НЕ нужно. Повторить выбор — только если
   содержимое папки изменилось.

   Совет: чтобы локально тоже работало автоматически (как онлайн),
   запускайте проект через локальный сервер, например:
       python -m http.server
   и открывайте http://localhost:8000 — тогда bg_index.json подхватится
   сам, без выбора папки.


Зарезервированные имена (быстрый выбор фона по ценнику)
=======================================================
В режиме «Разные товары» на каждой строке есть compact-список фона
ценника. Четыре ярлыка в нём привязаны к конкретным именам файлов:

  Ярлык в списке     Имя файла (должен лежать в этой папке)
  -----------------  ----------------------------------------
  Остро              ostryi.png
  Томатный           tomatnyj.png
  Медовый            medovyj.png
  Яблочный           yablochnyj.png

ВНИМАНИЕ: имена файлов должны СОВПАДАТЬ с указанными (регистр не
критичен, расширение .png — обязательно). Иначе ярлык не подхватит файл.


ПРИМЕЧАНИЯ
==========
- В локальном (file://) режиме картинки хранятся в браузере на этом
  устройстве (IndexedDB). При очистке данных браузера их придётся
  выбрать заново.
- В онлайн-режиме картинки применяются как ссылки на файлы (не base64),
  поэтому кэшируются самим браузером и не загружаются повторно.
